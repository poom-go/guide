1. 반품 등록 화면 진입

반품 등록 대상 주문을 확인한 뒤, 반품 등록 화면으로 진입합니다. 실제 업무 화면 기준으로 주문번호와 대상 SKU를 먼저 확인한 상태에서 진입하는 것이 좋습니다.

2. 필수 입력 항목 확인

  • 주문번호 확인
  • 반품 대상 SKU 선택
  • 반품 수량 입력
  • 반품 사유 선택 또는 입력
  • 필요 시 메모/특이사항 기재

3. 등록 전 검토 포인트

잘못된 주문번호, SKU, 수량으로 등록되면 후속 검품/환불 처리까지 영향이 갈 수 있으므로 저장 전 아래 항목을 다시 확인하는 것을 권장합니다.
  • 주문번호가 정확한지
  • 선택한 SKU가 실제 반품 대상인지
  • 수량이 오입력되지 않았는지
  • 사유 코드 또는 사유 문구가 맞는지
