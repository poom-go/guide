1. 반송장 확인 화면 진입

반품 요청 상세 또는 관련 조회 화면에서 반송장 정보를 확인합니다. 반송장 번호, 택배사, 생성 상태를 우선 확인하는 흐름으로 안내를 작성하면 좋습니다.

2. 주요 확인 항목

  • 반송장 번호
  • 택배사
  • 반송장 생성 일시
  • 회수 진행 상태
  • 추적 가능 여부

3. 자주 발생하는 확인 포인트

반송장이 조회되지 않는 경우에는 아직 생성 전인지, 다른 상태값에 의해 노출 제한이 있는지 먼저 확인하는 안내를 함께 적어두면 좋습니다.
  • 반송장 미생성 상태인지 확인
  • 취소된 반품 건인지 확인
  • 반품 요청과 송장 정보가 서로 다른 건으로 연결되지 않았는지 확인
