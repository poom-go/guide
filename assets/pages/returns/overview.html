반품 기본 안내

이 페이지는 반품 업무의 허브 화면입니다. 여기에 반품 프로세스 전반에 대한 기본 설명을 자유롭게 작성하면 됩니다.

예시로 아래 내용을 넣을 수 있습니다.
반품은 등록 → 반송장 확인 → 입고/검품 → 결과 확인 순으로 처리되며, 상태에 따라 취소 가능 여부와 후속 조치가 달라질 수 있습니다.

운영 시 확인 포인트

  • 반품 요청 등록 시 주문번호, SKU, 수량, 사유가 정확한지 확인
  • 반송장 생성 또는 회수 진행 여부에 따라 취소 가능 조건 확인
  • 검품 완료 후 결과 상태와 후속 처리 여부 확인
  • 이슈 발생 시 CS/운영 담당자 확인 포인트를 함께 기록

반품 처리 흐름 예시

단계 설명 확인 포인트
1. 반품 등록 반품 요청을 생성하고 기본 정보를 입력합니다. 주문번호, SKU, 수량, 사유
2. 반송장 확인 회수 진행을 위한 반송장 정보를 확인합니다. 송장번호, 택배사, 생성 여부
3. 검품 진행 입고 후 상태 확인 및 검품을 진행합니다. 입고 여부, 검품 상태, 판정 결과
4. 결과 확인 최종 처리 결과를 확인하고 후속 조치를 진행합니다. 정상/불량/보류 여부, 환불/재출고 연계
