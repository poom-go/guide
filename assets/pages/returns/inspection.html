1. 검품 결과 확인 화면 진입

반품 건 상세 또는 검품 결과 조회 화면에서 현재 진행 상태와 최종 판정 결과를 확인합니다. 검품 단계가 나뉘어 있다면 상태별 설명을 함께 적어두는 것이 좋습니다.

2. 확인할 상태 예시

상태 의미 운영 확인 포인트
검품 대기 입고 또는 검품 시작 전 상태 입고 여부, 처리 지연 여부
검품 진행 중 현재 검품이 수행 중인 상태 담당자 확인 필요 여부
검품 완료 최종 판정이 완료된 상태 정상/불량/보류 결과 확인
추가 확인 필요 예외 상황 또는 별도 판단이 필요한 상태 CS/운영 후속 조치 연결

3. 후속 처리 메모 예시

  • 정상 입고 완료 후 환불 처리 연계
  • 불량 판정 시 내부 기준에 따른 처리 분기
  • 보류/예외 건은 담당자 메모 및 재확인 일정 기록
