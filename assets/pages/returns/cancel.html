1. 취소 대상 반품건 조회

먼저 취소하려는 반품 건을 조회하고 현재 진행 상태를 확인합니다. 반송장이 이미 생성되었거나 검품 단계에 진입한 건은 취소 가능 여부가 다를 수 있습니다.

2. 취소 가능 상태 확인

상태 취소 가능 여부 비고
등록 완료 가능 일반적으로 바로 취소 가능
반송장 생성 완료 확인 필요 회수 진행 여부 확인 필요
검품 진행 중 제한 가능 운영 정책에 따라 별도 확인
검품 완료 제한 가능 후속 처리 상태까지 함께 확인

3. 취소 처리 시 주의사항

  • 회수 요청이 이미 전달된 경우 후속 취소 절차가 필요할 수 있음
  • 검품이 시작된 경우 상태 롤백 가능 여부를 확인해야 함
  • 취소 사유 또는 내부 메모를 남겨 추후 이력 확인이 가능하도록 관리
